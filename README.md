# jadelje.github.io

Portafolio personal de Javier Delgado — Coordinador de Infraestructura, Cloud & Ciberseguridad, publicado en GitHub Pages.

**Sitio:** [jadelje.github.io](https://jadelje.github.io/)

## Tecnologías

- HTML5, CSS3 (custom properties, Flexbox, Grid)
- JavaScript puro (sin frameworks ni dependencias)
- Fuente: [Inter](https://fonts.google.com/specimen/Inter) vía Google Fonts

## Desarrollo local

```bash
python3 -m http.server 8000
```

Luego abre `http://localhost:8000` en el navegador.

## Despliegue

Push a la rama `main` — GitHub Pages despliega automáticamente desde la raíz del repositorio.

## Estructura

```
index.html          # Página principal
styles.css          # Todos los estilos
script.js           # Navbar, animaciones, menú móvil
assets/img/         # Favicon
```
